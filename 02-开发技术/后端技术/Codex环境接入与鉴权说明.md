# Codex 环境接入与鉴权说明

## 概念
本笔记用于记录 Codex/开发环境接入时的鉴权流程与安全要求，避免口口相传导致配置漂移。

## 机制/流程
1. 准备环境变量（Base URL、Token、用户名等）。
2. 在本地 shell 注入并验证可连通性。
3. 通过最小权限账号完成首次接入测试。
4. 将结果记录到项目配置文档，避免重复排障。

## 学习要点
- 区分测试账号与生产账号。
- 凭证管理走集中密钥系统，不落盘到公开仓库。
- 出错时先排查网络、证书、权限 scope。

## 高频面试问答
- Q：环境接入文档为什么重要？
  A：能显著减少新人搭建时间与重复排障成本。
- Q：如何避免 token 泄漏？
  A：使用短期令牌、最小权限、日志脱敏、定期轮换。

## 易错点
- 把敏感字段提交到 git。
- 本地成功但忽略 CI 环境差异。
