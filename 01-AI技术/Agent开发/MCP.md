# MCP 学习笔记（Model Context Protocol）

## 概念
MCP 是连接模型与外部工具/资源的标准协议，目标是把“工具调用”做成可互操作、可扩展的统一接口。

## 机制/流程
- Client 向 Server 发现能力（tools/resources/prompts）。
- 模型按任务选择工具并传参。
- 服务端返回结构化结果，进入下一轮推理。

## 学习要点
- 传输模式常见有 `stdio` 和 `HTTP`。
- 工具输出要结构化，方便模型消费。
- 权限控制和审计日志是生产必备。

## 高频面试问答
- Q：MCP 相比私有 function-calling 的价值？
  A：标准化协议降低接入成本，提升跨工具复用能力。
- Q：MCP 的风险点？
  A：过度授权、工具副作用不可控、返回格式不稳定。

## 易错点
- 只做“能调通”而不做“可观测”。
- 没有幂等设计导致重复调用副作用。

## 实战演练清单
- 用一个真实任务做 30 分钟限时复盘：先写目标、再写步骤、最后写结果与改进点。
- 把当前主题抽成 3 个“可复述模板”：定义模板、排障模板、面试回答模板。
- 记录一次失败样例：失败现象、根因、修复策略、可复用经验。

## 复习节奏建议
- D1：通读全文，口述核心概念（3-5 分钟）。
- D3：只看“高频问答”和“易错点”，做一次自测。
- D7：结合实际项目或面试题，写一页应用案例。
- D14：回看旧结论，删除过时信息并补充新实践。
