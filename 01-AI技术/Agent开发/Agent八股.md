# Agent 八股（高频面试口径）

## 概念
Agent 是“模型 + 工具 + 规划 + 记忆 + 反馈闭环”的组合系统，关键在任务完成率而非单轮回答质量。

## 机制/流程
1. 任务理解与目标拆解。
2. 选择工具并执行。
3. 根据观察结果迭代调整。
4. 达到终止条件并输出结果。

## 学习要点
- 重点讲清“为什么需要工具调用”。
- 重点讲清“如何防止失控调用”。
- 重点讲清“如何评估 Agent 成功率”。

## 高频面试问答
- Q：Agent 和 Workflow 有什么区别？
  A：Workflow 路径固定；Agent 会基于环境动态决策。
- Q：如何做多轮对话状态管理？
  A：短期上下文 + 长期摘要记忆 + 关键状态落盘。
- Q：如何做评测？
  A：任务集、成功率、平均步数、工具失败恢复率。

## 易错点
- 忽略终止条件和预算上限。
- 缺少人工兜底策略。

## 实战演练清单
- 用一个真实任务做 30 分钟限时复盘：先写目标、再写步骤、最后写结果与改进点。
- 把当前主题抽成 3 个“可复述模板”：定义模板、排障模板、面试回答模板。
- 记录一次失败样例：失败现象、根因、修复策略、可复用经验。

## 复习节奏建议
- D1：通读全文，口述核心概念（3-5 分钟）。
- D3：只看“高频问答”和“易错点”，做一次自测。
- D7：结合实际项目或面试题，写一页应用案例。
- D14：回看旧结论，删除过时信息并补充新实践。
