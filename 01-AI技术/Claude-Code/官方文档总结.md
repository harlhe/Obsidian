# Claude Code 官方文档总结

## 概念
Claude Code 的核心价值是“把模型推理与工程动作打通”：读仓库、执行命令、修改文件、提交结果。

## 机制/流程
1. 明确目标与约束。
2. 先探查后改动，降低误改风险。
3. 小步提交，保证可回溯。
4. 用测试与检查闭环验证结果。

## 学习要点
- 提示词应包含目标、约束、验收标准。
- 复杂任务优先拆分为可验证子任务。
- 对高风险命令（删除、覆盖）必须加安全网。

## 高频面试问答
- Q：为什么需要“中间状态更新”？
  A：保证人机协作可见性，便于及时纠偏。
- Q：文档总结的输出标准是什么？
  A：可执行、可复核、可迁移。

## 易错点
- 把“总结”写成原文摘抄，缺少工程动作指引。
- 忽略失败路径与回滚策略。

## 实战演练清单
- 用一个真实任务做 30 分钟限时复盘：先写目标、再写步骤、最后写结果与改进点。
- 把当前主题抽成 3 个“可复述模板”：定义模板、排障模板、面试回答模板。
- 记录一次失败样例：失败现象、根因、修复策略、可复用经验。

- D7：结合实际项目或面试题，写一页应用案例。
- D14：回看旧结论，删除过时信息并补充新实践。
