# DevStar 测试场景与实践

## 概述

本文档基于 DevStar 平台的 23 种测试场景，详细说明测试场景的定义、分类、实施方法和实践经验，为 AI 自动化测试在真实项目中的应用提供参考。

## DevStar 平台简介

DevStar 是一个云原生 DevOps 平台，提供代码仓库管理、协作开发、云开发环境、CI/CD 等功能。

### 核心功能模块

- **平台接入**：用户登录、会话管理、首页展示
- **仓库管理**：仓库创建、Git 同步、协作评审
- **云开发**：DevContainer 创建、IDE 集成
- **协作功能**：Issue 创建、PR 创建与合并
- **AI 集成**：MCP 服务集成、AI 辅助开发
- **CI/CD**：Runner 注册、Workflow 执行、Artifact 管理

## 测试场景详细说明

### 安装与平台场景

#### platform-access-ready（平台接入准备度）

**测试目标**
判断当前实例是否已经达到可以继续做产品测试的基本状态

**测试步骤**
1. 访问 DevStar 平台首页
2. 检查页面是否正常加载
3. 验证关键元素是否可见
4. 确认无严重错误

**验收标准**
- 页面加载时间 < 3 秒
- 关键导航元素可见
- 控制台无严重错误
- 响应状态码为 200

**失败情况**
- 页面无法访问
- 加载超时
- 关键功能异常
- 服务器错误

#### account-session-ready（账号会话准备度）

**测试目标**
判断账号与会话是否具备进入后续链路的条件

**测试步骤**

2. 验证会话有效性
3. 确认用户信息正确
4. 测试会话保持功能

**验收标准**
- 会话状态正常
- 用户信息完整
- 权限配置正确
- 会话超时机制有效

**失败情况**
- 会话失效
- 权限不足
- 用户信息错误
- 会话管理异常

#### platform-first-impression（平台首屏观感检查）

**测试目标**
从首页入口视角检查页面是否具备继续验证条件

**测试步骤**

3. 验证视觉设计
4. 测试响应式布局

**验收标准**

- 色彩搭配合理
- 响应式适配良好
- 加载速度适中

**失败情况**
- 布局错乱
- 样式异常
- 响应式问题
- 性能问题

- 文档链接有效

**失败情况**
- 入口难以找到
- 引导信息不清楚
- 操作流程复杂
- 文档链接失效

#### install-first-login-ready（安装后首次登录验收）

**测试目标**
检查安装完成后的第一条登录链路

**测试步骤**
1. 完成安装流程

**示例**
```bash
# 运行登录测试
./qa-all.sh --goal "测试 DevStar 登录功能，使用测试账号 test_user，验证登录后能进入用户主页"

```

#### 使用 OpenClaw + Playwright

**适用场景**

1. 定义测试场景
2. 生成 Playwright 测试代码

- 性能严重下降

**P2 - 一般问题**
- 次要功能异常

- 性能轻微下降

**P3 - 轻微问题**
